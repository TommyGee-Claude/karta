# Karta pozemku – náhledy odkazů

Mezistránky pro odkazy z Vyhledávače pozemků: WhatsApp a další aplikace z nich vezmou náhled (obrázek radaru s pozemkem), stránka hned přesměruje na kartu ve Vyhledávači.
Generuje je `sync/nahledy/generuj.js` v repozitáři vyhledavac-pozemku (jen karty Vítězů; ostatní odkazy `?k=<id>` mají obecný náhled).
